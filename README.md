## 🎯 What is holaOS?

holaOS is a powerful desktop application that brings all your AI tools into one single place. Think of it as a mission control center for artificial intelligence — you can run different AI agents like Claude Code or Codex, connect them to over 100 popular tools and services, and give them access to your files, browser, and apps, all while they share a common memory.

If you've ever felt overwhelmed switching between different AI chat windows, command-line tools, and browser tabs, holaOS solves that chaos. It creates one unified workspace where all your AI helpers work together seamlessly.

## ❓ Frequently Asked Questions

### Do I need to know programming to use holaOS?
Absolutely not! holaOS is designed for everyone. The interface is visual and intuitive. If you can use a web browser, you can use holaOS.

### Which AI agents work best?
Claude Code and Codex are pre-configured and work excellently. But you can also integrate other MCP-compatible agents. Experiment and find what fits your workflow.

### Can I use my existing AI subscriptions?
Yes! If you already have API keys for services like Anthropic or OpenAI, simply add them in the settings. This is the "Bring Your Own Key" feature.

### Is holaOS really free?
The core application is completely free and open-source. Some premium AI models may charge usage fees through their own services, but the holaOS software itself costs nothing.
